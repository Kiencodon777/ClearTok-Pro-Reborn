# Release requirements

- Every push to main must build a separate versioned GitHub Release; never overwrite a previous version for new source changes.
- Keep APK and unsigned IPA from the same commit in one release. Versioning is generated by `.github/workflows/release.yml` as `2.3.<run_number>` and passed to Flutter.
- Validate IPA metadata at `Payload/<app>.app/Info.plist` and the declared executable before publication. Never rename an Actions artifact ZIP to `.ipa`.
